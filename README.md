# Gym Tracker

Особистий трекер тренувань: програма на 4-тижневий цикл, журнал підходів,
таймер відпочинку, заміри тіла й аналітика прогресу.

**Відкрити:** https://ilkiwwww.github.io/gym-tracker/

## Що вміє

- **Програма** — цикл Upper/Lower на 4 тижні, перемикання тижнів і днів.
  Клік по вправі показує цільові м'язи, техніку та варіанти заміни.
- **Тренування** — ваги й повтори по підходах, підказка «минулого разу»,
  автопідстановка ваги, таймер відпочинку з сигналом.
- **Аналітика** — графік робочої ваги по вправі та історія тренувань.
- **Тіло** — вага, відсоток жиру й обхвати, графіки динаміки, ІМТ.
- **Профіль** — хмарна синхронізація, експорт та імпорт даних у JSON.

## Як поставити на телефон (без App Store)

Трекер — це PWA: його можна додати на головний екран, і він відкриватиметься
як окремий застосунок із власною іконкою, без адресного рядка й навіть без інтернету.

- **iPhone (Safari):** відкрити сайт → «Поділитися» → «На екран "Додому"».
- **Android (Chrome):** меню ⋮ → «Установити застосунок».

Вхід у хмару в такому застосунку — за кодом із листа (посилання з пошти на iPhone
відкривається в Safari, а не в застосунку). У Supabase в шаблоні листа Magic Link
має бути `{{ .Token }}`.

## Дані

Усе зберігається локально в браузері (localStorage) і нікуди не надсилається.
У кожного браузера й пристрою свої дані. Для перенесення — «Експорт» у профілі,
потім «Імпорт» на іншому пристрої.

## Локальний запуск

```bash
python3 serve.py
```

Відкрити http://localhost:4321

## Структура

- `index.html` — розмітка
- `styles.css` — стилі
- `app.js` — логіка трекера
- `program.js` — програма тренувань і довідник вправ
- `serve.py` — локальний сервер без кешування
- `sw.js`, `manifest.webmanifest`, `favicon.svg`, `assets/icons/` — PWA: офлайн-режим та іконки
